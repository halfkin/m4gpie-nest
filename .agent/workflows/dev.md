# Running the m4gpieOS Dev Server

// turbo-all

1. Install dependencies (if not already installed):
```bash
cd "/Users/halfkin/Coding/Projects/Main Projects/website"
npm install
```

2. Start the dev server:
```bash
cd "/Users/halfkin/Coding/Projects/Main Projects/website"
npm run dev
```

3. Open http://localhost:3000 in the browser
